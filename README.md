# News Portal Website

## Overview
A responsive news portal website developed using HTML, CSS, and JavaScript. The website provides users with a clean interface to browse and read news articles across different categories.

## Features
- Responsive design for desktop and mobile devices
- Organized news categories
- User-friendly interface
- Interactive navigation menu
- Fast and lightweight design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Objectives
- Improve front-end web development skills
- Create an attractive and responsive user interface
- Enhance user experience through simple navigation
